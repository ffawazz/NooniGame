# Nooni's Tactical Guide to Everyday Life

Cozy stealth-comedy puzzle-adventure. The **active project is the Godot version in [`godot/`](godot/README.md)**.

`Assets/`, `Packages/` and `ProjectSettings/` are the earlier Unity prototype. They are kept for reference and are no longer developed. `docs/` holds the original design notes and input map (the key bindings carry over).
